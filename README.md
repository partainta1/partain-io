# partain.io

Source for https://www.partain.io, served by GitHub Pages from `main` (root).

- `index.html` is the whole site. Styles are inline; the only external requests are two Google Fonts families.
- `img/troy-400.jpg` and `img/troy-800.jpg` are the hero photo at 1x and 2x; `img/og.jpg` is the 1200x630 social preview.
- `CNAME`, `.nojekyll`, `robots.txt`, `sitemap.xml`, `404.html` and `favicon.svg` are deploy files; keep them at the root.

To update the copy, edit `index.html` directly. Keep the photo files under 100 KB each.
